# UserFlow Frontend — React 19 + TypeScript + Vite

Production-grade B2B SaaS dashboard and custom theming engine.

## Scripts

- `npm run dev`: Start Vite development server at `http://localhost:5173/`
- `npm run build`: Type-check with `tsc -b` and produce production build with Vite
- `npm run typecheck`: Run TypeScript compiler (`tsc --noEmit`)
- `npm run lint`: Run `oxlint`
- `npm run preview`: Preview production build locally

## Environment Variables

Configured in `.env`:

```env
VITE_API_BASE_URL=http://localhost:5000/api
```
